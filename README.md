#  Smart Task Manager 

A modern task management web app built using HTML, CSS, and JavaScript.

##  Features
- Add / delete tasks
- Mark tasks as completed
- Priority system (Low / Medium / High)
- Due date support
- Dashboard stats
- Dark mode 
- LocalStorage support (data saved in browser)

##  Tech Stack
- HTML
- CSS
- JavaScript
